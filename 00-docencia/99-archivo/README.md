# Archivo histórico del diseño

Estos documentos preservan antecedentes y no forman parte de la entrega a estudiantes. Las rutas escritas dentro de documentos históricos pueden describir estructuras anteriores; para localizar la versión vigente consulta el [registro de migración](../00-bitacora/migracion-estructura-2026-09-10.md).

- [Estructura anterior](estructura-anterior-2026-09-10.zip): respaldo íntegro de los 154 archivos existentes antes de reorganizar por destinatario, excluido el directorio interno `.git`. Contiene fuentes, HTML, recursos, lecturas y exportaciones originales.
- [Bitácora mixta anterior](bitacora-mixta-antes-separacion-2026-09-10.qmd): fuente histórica que mezclaba instrucciones estudiantiles y decisiones del curso; se conserva para descarga, no como capítulo vigente.
- [Conversación archivada sobre agentes](reporte_conversacion_agentes.md): antecedente de la conversación; no es documentación actual verificada de productos.

La configuración previa a la conversión en libro se conserva en `quarto-antes-libro-2026-09-11.yml` dentro del repositorio.

El respaldo no debe extraerse sobre el proyecto activo sin revisar los destinos. La estructura vigente se describe en el [README raíz](../../README.md).
